# AFR Decoder Fixtures

These silent, procedural `testsrc2` clips are generated by
`scripts/generate-afr-test-fixtures.ps1` using FFmpeg, not downloaded content.
They are test assets only and are not included in production APKs.

- `film-23976.mkv`: H.264 at 24000/1001 fps, millisecond Matroska timestamps.
- `pal-25.mp4`: H.264 at 25 fps.
- `video-5994.mkv`: H.264 at 60000/1001 fps, millisecond Matroska timestamps.

`PlaybackFrameRateDeviceTest` uses ARVIO's video-renderer wrapper and real decoded
presentation timestamps. Missing/incorrect-metadata cases override only the
declared frame rate, leaving decoder timing untouched. Detection latency is
measured from the first decoded frame, separately from player startup.

These tests verify cadence detection, not physical HDMI switching, HDR support,
or playback of the specific streams in a user report. Those need real hardware.
