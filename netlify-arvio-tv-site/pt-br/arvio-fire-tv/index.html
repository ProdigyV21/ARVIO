Perguntas frequentes

ARVIO no Fire TV: FAQ

O ARVIO está na Amazon Appstore?

A disponibilidade pode variar. O método documentado é instalar o APK oficial do GitHub em hardware compatível.

O mesmo APK funciona em todo Fire TV?

Não há garantia para todos os modelos. Desempenho e codecs variam conforme hardware e versão do Fire OS.

Posso atualizar sem perder dados?

Sim, quando o novo APK usa o mesmo pacote e assinatura oficial. Não desinstale o app se quiser preservar os dados locais.
