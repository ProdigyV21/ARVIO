A practical first session

Try two servers before moving your routine.

You do not need to move files, rebuild libraries or stop using your existing clients. Install ARVIO beside them and check the workflow with media you are authorized to access.

  1. Name each connection clearly

    Use names such as “Living room Jellyfin” and “Plex library.” Add one server first, open a known title, then add the second. Your server password belongs in the app's connection form, never a shareable collection.

  2. Check which library you are browsing

    Open Library → Homeserver and select the server and library. The same movie on two servers stays in separate libraries; ARVIO does not promise a merged, automatically deduplicated library.

  3. Test the details that matter to you

    Play a movie and an episode; check sound, subtitles and returned media versions. Leave and reopen the title to check resume. Do not infer full two-way server sync from one successful playback.

  4. Add discovery separately

    A Home collection can organize TMDB discovery or public lists. It does not create a server library or guarantee a playable source for every result. Configure Trakt or Simkl only if you want that additional tracking connection.

The Android app is free. Browser use has separate setup and playback limits, with a choice of free self-hosting or optional managed hosting.

Android TV, Google TV and Android mobile

How to connect each media server.

Install ARVIO from Google Play or the official APK release. You need an account authorized to access each server and an address the device can reach. Prefer HTTPS and include any required port or reverse-proxy base path.

  1. Jellyfin: add a server or use Quick Connect

    Open Settings → Home Server → Add server. Enter an optional Server name, the Server URL, Username and your password in Password / token. Alternatively, choose Connect with code, enter the Jellyfin URL and approve the code from a signed-in Jellyfin client. The Jellyfin Android TV guide explains the full flow.

  2. Emby: use the server's username and password

    Choose Settings → Home Server → Add server and enter the Emby server URL and your account credentials. ARVIO detects the server from its address. The Connect with code flow does not support Emby; use this form instead.

  3. Plex: connect with the displayed code

    Choose Settings → Home Server → Connect with code. You can leave Server URL empty for Plex discovery, or enter a preferred Plex server address. Follow the displayed activation instructions on your phone or computer and sign in to the Plex account with access to that server. Wait for ARVIO to finish connecting.

  4. Check one connection before adding the next

    Open Library → Homeserver and choose a library from the connected server. Play a known title before adding more servers. Settings → Home Server → Test connection checks whether this profile can reach its saved servers.

These are client connections, not server installations. Manage users, sharing, file locations and library scans in Plex, Emby or Jellyfin itself.

Separate libraries, familiar controls

What “one app” means in practice.

ARVIO provides a common interface for connected servers. It does not combine their databases or change which titles an account is allowed to access.

Choose a named server library

In Library → Homeserver, choose the library belonging to the server you want. Names help distinguish, for example, a local Jellyfin movie library from a shared Plex movie library.

Search, sort and refresh

Search the selected library or open Filters. Sort options include Recently added and Title A-Z; Refresh reloads the library. Clear active filters if expected titles are missing.

Recognize where a source comes from

Available playback sources can carry a server label and media details. When multiple versions are returned, choose the one suited to your device. Source availability still depends on permissions and title matching.

Keep expectations about sync clear

A server connection is not a promise of identical watched state across every client. Optional ARVIO Cloud, Trakt and Simkl integrations have their own roles; test the resume and tracking behavior your setup needs.

Browser companion

Connecting servers in ARVIO Web is different.

In the web app, open Settings → Home Server, choose Jellyfin / Silo, Emby or Plex, and enter a name and server URL. Use the following credentials, click Test, then Add to save a working connection.

ServerCredentials in the web form
Jellyfin or EmbyAn authorized API token or the server username and password. The Android code-sign-in instructions do not describe this web form.
PlexAn X-Plex-Token is required. Keep it private: it is an access credential, not a public share link. The web form does not offer the Android Plex PIN flow.

Hosted web requests cannot use the metadata proxy to reach private LAN addresses. If you self-host for a local server, follow the network and authentication guidance in the self-hosting documentation. Browser media support, cross-origin restrictions and HTTPS still matter.

For device support, local storage and hosting choices, read the ARVIO Web guide. The free Android app does not require Premium; optional managed web hosting and independent self-hosting are separate choices.

Practical answers

Multi-server setup FAQ.

Can I connect Plex, Emby and Jellyfin at the same time?

Yes. ARVIO supports multiple saved home-server connections. Add each server separately and choose its library in the Library screen. Each server keeps its own files, accounts, permissions and library organization.

Does ARVIO merge duplicate movies across servers?

No automatic cross-server library deduplication is promised. You browse identifiable server libraries, and matched titles can have multiple source choices. ARVIO does not move files or combine the servers into a new shared database.

Why does server login fail?

Check the complete server URL, port, any base path and the credentials for that server. Android supports Plex PIN and Jellyfin Quick Connect through Connect with code; Emby uses the username-and-password form. The web form differs: Plex requires an X-Plex-Token, while Jellyfin and Emby accept a token or username and password.

The library loads, but playback fails. What next?

Check that the same account can play the item in the server's own client. Then check the media URL, network, codecs, audio and subtitles on the ARVIO device. Try another available media version. A working metadata connection does not guarantee direct play or automatic transcoding.

Can hosted ARVIO Web reach a private LAN server?

The hosted metadata proxy blocks private LAN addresses. A secured, self-hosted ARVIO Web installation has a documented private-network option, but browser HTTPS, cross-origin and codec restrictions still apply. Do not disable server authentication or expose an unrestricted proxy to solve a connection problem.

Do I need Premium to connect a media server on Android?

No. The Android app is free. Premium is optional managed ARVIO Web hosting, not a requirement for the Android server connection. You must supply your own authorized server access and any separate services or subscriptions you choose to use.
