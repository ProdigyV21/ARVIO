Å legge til en server kopierer ingen filer og omgår ingen rettigheter. Den opprinnelige Plex-, Emby- eller Jellyfin-serveren må være tilgjengelig for visning og avspilling.

Vanlige spørsmål

Plex, Emby og Jellyfin: FAQ

Kan jeg koble til Plex, Emby og Jellyfin samtidig?

Ja. De kan kobles til samme profil og åpnes som separate bibliotekkilder.

Endrer eller slår ARVIO sammen bibliotekene?

Nei. Hver server forblir den offisielle kilden. ARVIO flytter eller endrer ikke mediene.

Hvorfor kan en tittel ha flere kilder?

Serveren kan tilby flere filer eller versjoner, og ARVIO viser dem slik at du kan velge oppløsning og koding.
