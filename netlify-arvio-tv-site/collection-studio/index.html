The next chapter

Put your collection
where you watch.

A collection organizes metadata. No playable media is included. Sender and recipient each use their own sources they are authorized to access.

1

Copy your JSON

Use Copy JSON above. A downloaded file is useful for sharing or hosting; direct file uploads into ARVIO are not currently supported.

2

Import it in ARVIO

On Android, open Settings → Catalogs → Import Catalog Pack / Collections and paste the JSON. On ARVIO Web, open Settings → Catalogs (Home Rows), paste it into Collection, and choose Import collections.

3

Find your new Home row

Open a folder to browse its titles. Public list access and service availability are required; Studio cannot verify them. Import into the profile you want to use.
