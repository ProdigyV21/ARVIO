Vanliga frågor

ARVIO på Fire TV: FAQ

Finns ARVIO i Amazon Appstore?

Det kan variera. Den dokumenterade metoden är att installera den officiella APK-filen från GitHub på kompatibel hårdvara.

Fungerar samma APK på alla Fire TV?

Det finns ingen garanti för alla modeller. Prestanda och kodekar varierar med hårdvara och Fire OS-version.

Kan jag uppdatera utan att förlora data?

Ja, när den nya APK-filen har samma paket och officiella signatur. Avinstallera inte appen om du vill behålla lokal data.
