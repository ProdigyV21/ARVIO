En Bibliotek-sida, separata källor.

Varje server förblir en egen, betrodd källa. Du växlar mellan bibliotek med samma kortdesign, detaljvyer och fjärrkontrollbeteende.

Separerat per server

Plex, Emby och Jellyfin hålls isär, så att behörigheter och struktur i varje bibliotek bevaras.

Sidofält för bibliotek

Nyligen tillagt

Inställningar per profil

Låt kontrollen ligga på rätt ställe.

Anslut en server

Använd inloggningen eller det anslutningsflöde som stöds för Plex, Emby eller Jellyfin.

Välj bibliotek

ARVIO läser bara de bibliotek som den inloggade användaren har tillgång till.

Välj en version

Öppna en titel och välj bland de medieversioner som servern rapporterar.

Ingen biblioteksflytt

Att lägga till en server kopierar inga filer och kringgår inga behörigheter. Den ursprungliga Plex-, Emby- eller Jellyfin-servern måste vara nåbar för bläddring och uppspelning.

Vanliga frågor

Plex, Emby och Jellyfin: FAQ

Kan jag ansluta Plex, Emby och Jellyfin samtidigt?

Ja. De kan kopplas till samma profil och öppnas som separata bibliotekskällor.

Ändrar eller slår ARVIO ihop biblioteken?

Nej. Varje server förblir den officiella källan. ARVIO flyttar eller ändrar inte medierna.

Varför kan en titel ha flera källor?

Servern kan erbjuda flera filer eller versioner, och ARVIO visar dem så att du kan välja upplösning och kodning.
