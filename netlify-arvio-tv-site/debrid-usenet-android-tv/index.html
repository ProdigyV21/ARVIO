Use debrid and Usenet sources on Android TV.

ARVIO can play compatible debrid and Usenet sources returned by a configured addon. Use its TV interface to browse titles, compare source details and select a playable result. You bring the addon, provider account and permission to access the media.

A player, an addon and a provider do different jobs

ARVIO is the player

The free Android app provides the TV interface and playback controls. Install it on Android TV or Google TV from an official download. For Fire TV, first check the Fire OS compatibility guide.

The addon supplies sources

A compatible addon connects the title you select to source results. Some addons only supply catalogs or subtitles. A catalog of posters alone does not provide playable video.

The provider supplies access

Configure the required account with the addon separately. Debrid and Usenet are different services; the relevant integration must return a source that resolves to accessible HTTP or HTTPS media.

Your device handles the format

The TV, audio setup and connection still determine which files play well. A 4K badge is source metadata, not a guarantee that every TV can decode its video or audio.

This is an addon-based playback setup, not a native debrid cloud manager or an NZB downloader. No debrid or Usenet subscription is bundled with ARVIO.

Set up a debrid or Usenet addon in ARVIO

  1. Configure a compatible addon

    Use an addon from a service you trust and are authorized to use. Complete its own configuration, including the provider account if required, then copy the configured manifest URL. It often ends in /manifest.json. Keep URLs containing account tokens private.

  2. Install the manifest on your TV

    Open Settings → Addons → Add Addon, paste the configured URL and review the addon before installing it. If another configuration is already installed, choose Replace installed or Keep both deliberately.

  3. Finish any required setup

    An addon marked Setup required needs configuration before it can supply results. If using the phone QR flow, tap Install in ARVIO on the phone after configuring, then Refresh Addons on the TV. Cross-device restoration requires a valid ARVIO Cloud session with the same account and intended profile. Without cloud sync, paste the configured manifest directly on the TV.

  4. Test a source you can access

    Open a title supplied by your setup and inspect its sources. Select a result your provider makes available and your device can play. Test one working configuration before adding more. See the full addon guide for catalog, stream and subtitle differences.

Compare source details before starting playback

When supplied by the addon, ARVIO can display quality, file size, filename, language and addon or provider attribution. These details help distinguish multiple results for the same title. Missing metadata does not establish that a source is broken, and a provider label alone does not confirm that your account can access it.

Choose a source suited to your connection and hardware. If one version fails, try a different compatible result from your authorized provider. For captions and language preferences, see subtitles on Android TV.

Debrid and Usenet FAQ

Does ARVIO include a debrid or Usenet subscription?

No. The Android app is free, but third-party accounts and any required subscriptions are separate. ARVIO does not supply movies, source indexes, provider credentials or access rights.

Can ARVIO play torrent or magnet links directly?

No. Direct P2P torrent, magnet and infoHash-only playback is not supported. The addon or service must provide a media source that resolves to an accessible HTTP or HTTPS URL.

Is ARVIO a debrid cloud manager or Usenet downloader?

No. This setup uses ARVIO as a player for compatible addon-provided sources. It is not a native interface for managing a debrid cloud library, downloading NZB files or browsing a Usenet indexer.

Will every debrid provider and addon work?

Compatibility depends on the configured addon, its returned URL, the provider account and the media format. A provider name in a source label does not prove compatibility. Test an authorized source on your device before relying on a particular combination.

Can I use these sources on an iPhone, iPad or computer?

ARVIO Web can install compatible addon manifests in a supported browser. Browser codecs, network access and provider restrictions differ from Android playback. Managed hosting is optional; self-hosting is also available. A working Android source is not a guarantee of browser playback.

Read the ARVIO Web guide for browser installation and playback limitations.
