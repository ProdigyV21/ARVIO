מדריכי מוצר

בונים מרכז מדיה מחובר משלך.

מתחילים באפליקציית Android החינמית, מארחים את ARVIO Web בשרת משלך או בוחרים בהצעה המאוחסנת. המדריכים האלה עוזרים לחבר את המקורות ולבדוק את המכשיר.

iPhone ו-iPad · באנגלית

ARVIO ב-iPhone וב-iPad

פתיחת ARVIO Web ב-Safari, התחברות עם חשבון ARVIO, הוספה למסך הבית, ובדיקת הכול לפני התשלום.

הגדרת תוספים · באנגלית

תוספים התואמים ל-Stremio ב-ARVIO

התקנת כתובת manifest, הגדרה דרך הטלפון ובדיקת גבולות התאימות ב-Android TV.

התאמה אישית · באנגלית

יצירת אוספים והוספת קטלוגים

תבניות JSON, אירוח חינמי וייבוא לפי כתובת למסך בית משלך.

עורך אוספים · באנגלית

Collection Studio

בניית שורה במסך הבית עם עד שמונה תיקיות, העתקת ה-JSON אל ARVIO ושיתוף תצוגה מקדימה ציבורית.

חינם בדפדפן · באנגלית

אירוח עצמי עם Docker או Node.js

פקודות התקנה, מפתחות API משלך, פרופילים מקומיים, גישה ברשת ועדכונים.

הפעלה בדפדפן · באנגלית

בדיקת המקור הראשון

זיהוי בעיות גישה ופורמט, ובדיקת טלוויזיה חיה או שרתים במכשיר שלך.

פרופילים, שרתים, מעקב, טלוויזיה חיה, כתוביות והפעלה ב-Android ובדפדפן.
