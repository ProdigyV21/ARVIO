אינטגרציות אישיות תואמות

מקורות Debrid ו-Usenet, ממוינים בבהירות.

שימוש במקורות מתוספים תואמים באפליקציית Android החינמית או ב-ARVIO Web האופציונלית. ARVIO שומרת את פרטי המקור ומפעילה מדיה HTTP שנפתרה במכשירים נתמכים.

בחירה שקופה

רואים לפני ההפעלה מה התוסף מספק.

תוסף תואם יכול לספק הרבה יותר מכתובת אחת. ARVIO מציגה את הפרטים השימושיים כדי שאפשר יהיה לבחור במודע.

איכות ורזולוציה

זיהוי 4K, 1080p, 720p ומאפיינים נוספים שצוינו בתגים אחידים.

גודל ושם קובץ

השוואת הגודל שצוין וקריאת שם הקובץ המלא, כשהתוסף מספק את הערכים האלה.

מקור התוסף והספק

תוויות כמו Debrid, Usenet, Vault, Index או Host נשמרות, במקום להציג הכול כמקור כללי.

שפה ופרטים טכניים

שפה, מהדורה, קודק ומטא-דאטה זמינה נוספת — בלי כפילויות מיותרות.

מיון הגיוני

סדר התוספים נשמר; אפשר להשוות גודל ואיכות כדי לאתר במהירות את האפשרויות המועדפות.

Android ודפדפן

שימוש בנגן המקורי או באפשרויות נתמכות כמו דפדפן, VLC ו-Infuse — לפי השירות, הפורמט והמכשיר.

התוסף פותר, ARVIO מציגה ומפעילה.

הגדרת האינטגרציה

הגדרת תוסף או שירות תואמים בנפרד — עם חשבון שמורשה לך.

קבלת מקורות שנפתרו

האינטגרציה מספקת מטא-דאטה וכתובת HTTP שניתנת להפעלה. ARVIO אינה סורקת תשתית Usenet או Debrid.

בחירה או הפעלה אוטומטית

בחירת תוצאה מסוימת, או הפעלה אוטומטית שבוחרת את המועמד הזמין הטוב ביותר לפי ההעדפות שלך.

ללא חשבונות, תוספים או מדיה

ARVIO אינה מספקת מנויים, אינדקסים, פרטי הזדהות, קבצים או זרמים, ואינה מציעה הפעלת P2P ישירה. יש להשתמש רק בשירותים ובתכנים שמורשה לך להשתמש בהם.

מקורות Debrid ו-Usenet: FAQ

האם ARVIO כוללת חשבון Debrid או Usenet?

לא. ARVIO אינה כוללת, מוכרת או משתפת חשבונות ספקים.

האם ARVIO מפעילה טורנטים או קישורי מגנט ישירות?

לא. האינטגרציה חייבת לספק מקור מדיה HTTP שנפתר ושהמכשיר יכול לגשת אליו.

אילו פרטי מקור יכולים להופיע?

איכות, גודל, שם קובץ, שפה, תוסף, ספק ופרטים נוספים שהאינטגרציה מעבירה.
