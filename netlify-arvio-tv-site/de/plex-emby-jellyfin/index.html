Server wechseln, Oberfläche behalten

Eine Bibliotheksseite, getrennte Quellen.

Jeder Server bleibt eine eigenständige, maßgebliche Quelle. Du wechselst zwischen Mediatheken und behältst dabei dasselbe Kartendesign, dieselben Details und dieselbe Fernbedienungssteuerung.

Getrennt nach Server

Plex, Emby und Jellyfin bleiben getrennt – Berechtigungen und Struktur jeder Mediathek bleiben erhalten.

Mediatheken in der Seitenleiste

Wähle einen verbundenen Dienst und öffne seine Mediatheken ohne überladene Filter.

Neue Inhalte

Sieh die neuesten freigegebenen Titel jedes Servers in einer Ansicht, die sich schnell überfliegen lässt.

Mehrere Medienversionen

4K-, 1080p-, Remux- oder alternative Fassungen können als getrennte Optionen erscheinen.

Einheitliche Bedienung

Details, Artwork, Metadaten und Steuerung bleiben vertraut – egal von welchem Server der Titel stammt.

Einstellungen pro Profil

Lege fest, welche Server und Kataloge in welchem Profil sichtbar sind – auch im Familien-Setup.

Die Kontrolle bleibt, wo sie hingehört.

Server verbinden

Nutze die unterstützte Anmeldung oder Verbindung für Plex, Emby oder Jellyfin.

Mediatheken wählen

ARVIO liest nur die Mediatheken, die für den angemeldeten Benutzer verfügbar sind.

Version auswählen

Öffne einen Titel und wähle eine der Medienversionen, die der Server meldet.

Keine Migration der Mediathek

Wenn du einen Server hinzufügst, werden weder Dateien kopiert noch Berechtigungen umgangen. Der ursprüngliche Plex-, Emby- oder Jellyfin-Server muss zum Durchsuchen und Abspielen erreichbar sein.

Häufige Fragen

Plex, Emby und Jellyfin: FAQ

Kann ich Plex, Emby und Jellyfin gleichzeitig verbinden?

Ja. Alle drei lassen sich mit demselben Profil verbinden und als getrennte Mediatheksquellen öffnen.

Verändert oder vermischt ARVIO die Mediatheken?

Nein. Jeder Server bleibt die maßgebliche Quelle. ARVIO verschiebt oder ändert keine Medien.

Warum hat ein Titel manchmal mehrere Quellen?

Der Server kann mehrere Dateien oder Fassungen anbieten. ARVIO zeigt sie an, damit du Auflösung und Kodierung wählen kannst.
