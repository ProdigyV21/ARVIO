# ARVIO 2.3.1 — Smoother browsing, better tracking

This update brings a more polished TV and mobile experience, more room for your libraries and playlists, and important playback and tracking fixes.

## Highlights

- **Better SIMKL syncing:** recover resume positions when imported playback lacks a runtime, preserve fractional progress, send a final update when closing the player, and keep queued updates through token refreshes without crossing account boundaries.
- **Larger MDBList collections:** remove the 96-title ceiling, load cards progressively in View All, and reuse cached list IDs across pages.
- **Up to ten IPTV playlists:** retain every configured source and improve playlist handling.
- **Collection genre filters:** narrow streaming-service collections by genre while preserving the other tab's state.
- **Refined profiles and navigation:** refreshed TV/mobile profile selection with smoother entry animation, a landscape navigation rail, and more consistent OLED surfaces, focus states and controls.
- **WeTrakr integration:** device sign-in, library integration and playback tracking.

## Playback and library fixes

- Restore the episode row's position and focus after playback instead of jumping back to episode one.
- Improve direct Play from Home and wait for the correct playback target before starting.
- Open the episode actually selected, including cached episode cards.
- Refresh expired resume links and improve source fallback handling, including sources with different access headers.
- Improve software audio decoding in the Play build and recovery from failed passthrough.
- Preserve manual subtitle choices and improve source language information.
- Fix watchlist writes with connected trackers and improve Trakt connection recovery and status messages.
- Restore an add-on's previously deleted catalogue rows when reinstalling it.
- Improve updater installation, notifications, and baseline-profile handling.
- **Seeking thumbnails are disabled for now** while their performance is improved.

## ARVIO Web and Cloud

The web and backend updates made during this release cycle also improve browser account isolation, settings and progress persistence, playback/source selection, Live TV handling, and details-page resilience to malformed metadata. Web updates are delivered separately from the Android download.

## Download

Install **ARVIO-v2.3.1-sideload-release.apk** to update the GitHub version. It is signed with the existing release key and supports ARM64 and ARMv7 devices. Google Play users receive the separate Play build through the store after Google's review.

ARVIO's Android app remains free and open source. Bring your own authorized media sources; no media subscription is included.
